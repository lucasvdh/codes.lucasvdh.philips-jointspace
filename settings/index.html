Diagnostic report

Generates a snapshot of one paired TV: its settings, cached state, capability values, and the result of probing every Jointspace endpoint we use. The report stays on your device; nothing is auto-sent. Use it when reporting an issue.

Paste the copied report into a new GitHub issue. The report contains your TV's local IP, MAC address and model serial - these are only useful on your home network, not a security risk to share. If you'd rather strip them before sharing, edit the text after pasting.
